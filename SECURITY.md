# Política de segurança

## Uso responsável

Esta ferramenta é **defensiva**: ela só *observa* conexões e tráfego já existentes.
Use apenas em sistemas e redes que você administra ou tem autorização por escrito para auditar.

## Reportando vulnerabilidades

Encontrou uma falha no próprio `revshell-hunter`? Abra um
[Security Advisory privado](../../security/advisories/new) no GitHub em vez de uma issue pública.
Responderei assim que possível.
